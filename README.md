# Credit Card Payment System

A backend project for managing users, credit/debit cards, and credit card payments using Django REST Framework and FastAPI.

## Technologies Used

- Python
- Django
- Django REST Framework
- FastAPI
- MySQL
- JWT Authentication
- Docker
- Docker Compose
- Swagger / OpenAPI
- Postman
